# Bahaa Elshikh — Portfolio

Personal portfolio website built with HTML, CSS & JavaScript.

## 🚀 How to Deploy on GitHub Pages

1. Create a new repository on GitHub (e.g. `portfolio` or `bahaaelshikh.github.io`)
2. Upload these 3 files:
   - `index.html`
   - `style.css`
   - `script.js`
3. Go to **Settings → Pages**
4. Set Source to **main branch / root folder**
5. Your site will be live at:
   - `https://BahaaElsheikh.github.io/portfolio` (if repo named `portfolio`)
   - `https://BahaaElsheikh.github.io` (if repo named `BahaaElsheikh.github.io`)

## 📁 Files

| File | Description |
|------|-------------|
| `index.html` | Main HTML structure |
| `style.css` | All styles + responsive design |
| `script.js` | Scroll animations + mobile nav |

## 🛠 Tech Stack
- Pure HTML5 / CSS3 / Vanilla JS
- Google Fonts (Syne + Space Mono)
- No frameworks, no dependencies
- Fully responsive (mobile, tablet, desktop)
